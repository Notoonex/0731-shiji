现有 9 个首页板块里，**8 个原样保留**，只有「群档案」要换掉。图库、看图器、回忆播放器、人物、旅程、地点这些图片相关的东西**一个都不动**。

## 二、新增：「话」

### 核心判断

**单句金句会丢上下文，群聊好笑的是一来一回。** 所以主形态是对话片段卡，不是名言卡。

### 四种形态

#### 1. 名场面（主形态，首页横滑 + 一级视图）

一张卡 = 一段 5～8 条的完整对话，保留发言人、头像、时间戳、接话节奏。

```
┌─────────────────────────────────┐
│ 2019年6月18日 · 毕业前夜         │
│                                 │
│ 那次说好一起去西藏               │  ← 自动生成的标题
│                                 │
│ 周斯年  23:14                   │
│   毕业了咱们去趟西藏吧           │
│ 陈屿    23:14                   │
│   走                            │
│ 苏念    23:15                   │
│   +1                            │
│ 林知遥  23:15                   │
│   我攒钱                        │
│ 何时    23:47                   │
│   我妈不让                      │
│                                 │
│ 47 条回复 · 后来被引用 12 次      │
└─────────────────────────────────┘
```

**怎么选出来**（四个信号加权）：
- 单位时间消息密度（那几分钟大家都在说话）
- 被回复/被引用次数
- 表情回应数
- 后续被重提次数（"还记得那次说要去西藏吗"）

#### 2. 群黑话词典

这个群独有的词。每条：词 + 第一次出现的日期 + 总次数 + 出处对话（点开是名场面卡）。

判定：词频显著高于通用语料基线（简单做法是对比一份常用词表），且首次出现后持续复现。八年的群通常有 10～20 个。

#### 3. 年度关键词

一条时间轴，每年 5 个关键词，点击展开那年的代表对话。

```
2017  军训 · 食堂 · 补考 · 篮球 · 熄灯
2019  毕业 · 答辩 · 散伙饭 · 西藏 · offer
2023  结婚 · 房贷 · 出差 · 孩子 · 体检
```

这条时间轴看下来是这群人的人生阶段，情绪冲击力很强。

#### 4. 数字小传

谁话最多、谁最晚睡、谁最爱发语音、最长的一次连续聊天、全群总字数。现在消息视图右侧的"活跃时段"图表已经是雏形，扩成一个板块。

## 三、新增：「聚会」

### 为什么这个比从照片识别容易

约饭的对话天生是结构化的：

```
提议    "周六一起吃个饭？"        召集句式 + 时间词
协商    "周六晚上七点" "老地方"    时间/地点收敛
应答    "来" "+1" "算我一个"      ← 最强信号
成行    当天 ±6h 的照片涌入        照片锚定，确认真去了
```

### 识别规则

**第一步 · 召集句捕捉。** 句式模板匹配：`{时间词} + {聚集动词}`（吃饭/聚/约/见/来/走起），或带问号的提议句。时间词覆盖绝对（周六、10 月 1 号）和相对（明天、下周）。

**第二步 · 应答聚类（最强信号）。** 召集句之后 30 分钟内，出现 ≥3 条短肯定句（"来""+1""算我一个""收到""👍"）。这个模式在日常闲聊里几乎不出现，误报率很低。

**第三步 · 时间地点收敛。** 从提议到应答之间的消息里抽取最终确定的时间和地点。多个候选时取最后一次提及的。

**第四步 · 照片锚定。** 约定时间点 ±6 小时内是否有照片涌入。有 → 标记「成行」，并把那批照片挂到这次聚会；没有 → 标记「没去成」。

**兜底**：识别结果都可以在详情页手动修正（"这不是一次聚会""其实去了"），修正作为负样本调整该群阈值。

### 展示形态

#### 聚会卡（首页横滑 + 一级视图）

```
┌──────────────────────────────────────┐
│ [当天最高分的照片，满溢]              │
│                                      │
│ 2019年7月20日 · 成行                 │
│ 散伙饭 · 老地方                       │
│ 8 人应约 · 6 人到场 · 126 张照片       │
│ ●●●●●● ← 到场者头像                  │
└──────────────────────────────────────┘
```

未成行的卡用另一种样式（无封面图、灰底、虚线边），标题是"说好要去的"。

#### 聚会详情

上半部分是**约的那段对话**（复用名场面卡的排版），下半部分是**当天的照片网格**。中间一条分隔："这一天真的发生了"。

这是整个产品最有说服力的一屏——左边是七年前说要去，右边是真的去了的照片。

#### 鸽王榜

| 人 | 应约 | 到场 | 到场率 |
|---|---|---|---|
| 陈屿 | 34 | 31 | 91% |
| 何时 | 28 | 12 | 43% |

**这个数据只有群聊 + 照片合起来才算得出来**，单独的相册和单独的聊天记录工具都做不到。

#### 未成行的约定

八年里说过要去但一直没去的地方，单独一个列表。这些对话本身就是记忆。

## 四、导航与首页顺序

### 导航

```
现在：首页 · 图库 · 回忆 · 人物 · 地点 · 群档案
改后：首页 · 图库 · 回忆 · 人物 · 地点 · 话
```

`groups` 这一项让给 `talks`。「聚会」不单独占导航位，走首页板块 + 从「话」视图进详情。

### 首页板块顺序

```
1  hero 今日精选          保留
2  为你回忆               保留
3  最近的日子             保留
4  聚会                   ← 新增（和 3 都是事件类，放一起）
5  人物                   保留（去掉"来自 X 群"）
6  旅程                   保留
7  地点                   保留
8  名场面                 ← 新增（从图切到文，换节奏）
9  不只是照片             保留
10 这一年的这一天          保留 + 增强（加当天对话）
11 相簿                   保留
12 群小传                 ← 替代原「群档案」
```

节奏上：前 7 个是图，第 8 个切到文字，第 9-11 回到图，最后用群小传收尾。

## 五、后端要产出什么

新增两张表：

```
conversation_highlight   名场面
  id, start_msg_id, end_msg_id, title, score,
  reply_count, quote_count, reaction_count, date

gathering                聚会
  id, proposed_at, scheduled_at, place, status(成行/没去成),
  proposer_id, responder_ids[], attendee_ids[],
  highlight_id,          → 关联约的那段对话
  photo_ids[]            → 关联当天的照片
```

外加两张派生表：`group_slang`（黑话词典）、`year_keyword`（年度关键词）。

|---|---|
| 单群重构 | 删 3 处（群档案视图、首页群卡板块、消息左侧栏），改文案若干。约占总量 20% |
